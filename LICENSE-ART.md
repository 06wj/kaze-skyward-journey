# 资源来源与第三方许可记录

本文件记录「风见之羽 · KAZE」交付资源的来源及直接依赖许可。原创项目内容没有在本文件中额外授予开源许可；第三方组件遵循各自的许可证。

## 本项目创建的资源

| 资源       | 来源与可编辑文件                                                                                                                                                                                  |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 燕子角色   | 本项目通过 Blender Python 脚本程序建模：分层羽翼、燕尾、眼睛、围巾及材质均在项目中创建。源文件：`scripts/create-bird.py`、`assets/blender/swallow.blend`；运行文件：`public/models/swallow.glb`。 |
| 城市与场景 | `src/render/world.ts` 中的程序几何与实例化构件，包括建筑、窗户、街道、桥梁、植被、招牌与河道。                                                                                                    |
| 天空与特效 | `src/render/sky.ts`、`src/render/effects.ts` 中创建的渐变天空、云层画布纹理、山体轮廓、风环、粒子与轨迹。                                                                                         |
| 音乐与音效 | `src/audio/audio.ts` 使用 Web Audio 的振荡器与噪声缓冲实时合成；未导入商业曲目、录音或采样包。                                                                                                    |
| 界面与图标 | 本项目的 HTML、CSS 与 `public/favicon.svg`。城市招牌采用虚构文案与程序绘制。                                                                                                                      |

这些资源未使用外部下载的角色模型、城市素材包、图片纹理或音频文件。Blender 是资源制作工具，其应用程序不包含在游戏发行文件中。

## 字体

界面和招牌使用本地字体堆栈，由玩家设备中已安装的字体及系统回退提供字形。当前项目不请求远程字体，也不分发字体文件。
